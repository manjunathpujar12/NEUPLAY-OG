# NEUPLAY Rehab Hub

Build a responsive web application for "NEUPLAY" – an AI-powered rehabilitation gaming system.
Focus Areas:
1. Doctor Dashboard (Primary)
   • Create patient profiles with fields: Patient ID, Name, Age, Condition.
   • Track patient progress: list of completed exercises, accuracy %, repetitions, and improvement trends.
   • Auto-generated weekly reports with charts (range of motion, accuracy, consistency).
   • Flagged concerns section (e.g., limited finger mobility, missed sessions).
   • Tabs: Patients | Reports | Settings.
   • Clean, professional UI with data tables and charts.
2. Patient Game (Secondary – Fingers Only)
   • Piano-playing game for fine motor skills.
   • Patients press virtual piano keys using finger movements tracked via AI.
   • Real-time feedback: Score, Reps, Accuracy %, Timer.
   • Motivational elements: sound effects, achievements, streaks.
Design Style:
• Modern, minimalistic, and accessible.
• React.js style components, HTML5, CSS3, and JavaScript interactions.
• Browser-based (no app install required).
• Calming healthcare color palette with playful accents for the game.
Accessibility:
• Works on any smartphone browser.
• Simple login for patients (Patient ID + Date of Birth).
• Doctor view optimized for desktop with charts and reports.
Goal:
Generate a prototype where the **Doctor Dashboard clearly shows patient recovery data** (finger exercises listed, tracked, and reported), while patients interact with a **piano-playing rehab game** that feeds progress into the dashboard.
